【怎么打开】
 1. 把整个文件夹解压出来（不要在压缩包里直接双击）。
 2. 进入  TCF法语学习助手  文件夹，双击  TCF法语学习助手.exe
 3. 稍等 3–10 秒，会自动打开浏览器，就可以用了。

【第一次打开时 Windows 可能会拦一下】
 如果出现蓝色窗口「Windows 已保护你的电脑」：
   点  更多信息  →  仍要运行
 这是因为软件没有花钱买数字签名（一年几百美元），不是病毒。

【★ 用微信发给别人时，一定按这个来】
 · 发送时选「文件」，不要拖进聊天框当图片发。
 · 对方收到后：先点「另存为」保存到桌面 → 右键「全部解压缩」→ 再双击 exe。
   直接在微信的临时文件夹里双击，基本打不开。
 · 如果微信提示文件不安全 / 发不出去（部分企业微信会拦 .exe）：
   改用 QQ 传文件、U 盘、或百度网盘 / 腾讯微云发链接。
 · 解压后如果看到的名字像 PDF，那是 Windows 隐藏了扩展名，看文件大小就知道。

【数据不会丢】
 生词本存在你电脑的 AppData\Roaming\TCFCoach 文件夹里（不是浏览器里），
 清浏览器缓存不会影响它。

【怎么关闭】
 点界面右上角的「⏻ 退出」按钮，程序就彻底关掉了。
 只关浏览器标签页的话，程序还在后台开着（平时没关系，下次双击会直接回到它），
 但是——★要拔 U 盘、要删掉或替换这个文件夹之前，必须先点「⏻ 退出」，
 否则 Windows 会提示"文件正在使用中"。

【关于重复双击】
 已经打开的时候再双击 exe，不会重复启动，会直接把网页调出来。

========================================
  Tâche 3 怎么用主题论点库
========================================
 抽到题 → 翻到对应主题 → 从 6 条好处里挑 2 条、6 条坏处里挑 1 条
 → 再选一句核心立场收尾，一篇论证就成型了。

 口语骨架：立场（1 句）→ 理由一 + 例子 → 理由二 + 例子
           → 让步一句（« C'est vrai que… mais… »）→ 结论
 写作骨架：一样，只是把停顿换成段落。

 ★ 例子那一列比论点那一列值钱。
   所有人都会说「科技让生活更方便」，
   只有你会说「我用手机 5 分钟就交完了房租」。

 ★ 别背满 10 个主题的全部。每个主题记熟 2 条好处 + 1 条坏处 + 1 句立场，
   就够应付这个主题下的任何题目。

========================================
  变位怎么背最省力（建议顺序）
========================================
 ① 先只背 être / avoir 的 6 行 —— 所有复合时态都靠它们。
 ② 再背 Présent + Passé composé 这两行的全部 9 个动词，
    这两个时态占口语实际用量的七成以上。
 ③ Conditionnel 只背 je 那一格：je serais / j'aurais / je voudrais /
    je pourrais / je devrais —— 这五个是全场最礼貌、最像 B2 的表达。
 ④ Subjonctif 先背 que je sois / que j'aie / que je puisse / que je fasse，
    配合 il faut que…、je voudrais que… 就够用。
 ⑤ 每天开背诵模式过一遍「连读」卡片，10 分钟。

 ★ 你是女生，别忘了：aller 和 venir 的复合过去时要配合阴性——
   je suis allée / je suis venue / je suis arrivée / je suis restée。
   读音一样，写漏 -e 就是考官一眼能抓的错。
